Σと数列の和

要点

まず覚えること

n∑k=1 1 = n
n∑k=1 k = n(n+1)2
n∑k=1 k² = n(n+1)(2n+1)6
n∑k=1 k³ = {n(n+1)2}²

Σの下の「k=1」は足し始める値、上の「n」は最後の値です。kに1、2、…、nを順に入れて足します。

式を展開して、公式を使える形に分けるのが基本。定数cをn個足すとncです。

等比数列の和：Sn = a(1−rⁿ)1−r　(r≠1)
r=1なら Sn=na

分数の和では、1k(k+1) = 1k − 1k+1 のように分けると、途中の項が消えます。

Σを実際の足し算に戻してみよう

例えば、上が「4」、下が「k=1」で、右に「k²」があれば、kを1から4まで変えて足します。

1² + 2² + 3² + 4² = 30

右側が「2k+1」なら、足すのは3、5、7、9です。Σの右にある式の全体が、足し算の対象になります。

公式を使うときは、最初に「kの和」「k²の和」「定数の和」に分けます。例えば3k−2なら、「kを足した結果の3倍」から「2をn個足した結果」を引きます。

迷ったら
n=3などの小さい数で書き出そう。一般式にその数を入れた結果と一致するか確認できます。

間違えやすいところ

ここに注意
Σの下がk=0、上がn−1などのときは項数に注意。定数の和は「定数×項数」です。

例題

例題｜問題と解く順番

n∑k=1 k(k+1) を求めよう。

この順番で解こう

  1. 中身を展開する
  2. 和を2つに分ける
  3. それぞれの和の公式を使う
  4. 分母をそろえて整理する

手順1｜中身を展開する

手順 1 / 4

考え方：kやk²の和の公式が使える形にするためです。

中身を展開する：k(k+1)=k²+k。

手順2｜和を2つに分ける

手順 2 / 4

考え方：足し算の和は、それぞれを足してから合計しても同じです。

和を分ける：n∑k=1k² + n∑k=1k。

手順3｜それぞれの和の公式を使う

手順 3 / 4

考え方：k²の和とkの和に、対応する公式を入れます。

公式を代入する：n(n+1)(2n+1)6+n(n+1)2。

手順4｜分母をそろえて整理する

手順 4 / 4

考え方：両方の項にあるn(n+1)をまとめると、答えを短く書けます。

共通因数でまとめる：n(n+1)(n+2)3。

練習

問題 1｜Σの計算

n∑k=1(3k−2) を求めよ。

答えと解説を見る

答え：n(3n−1)2

3n∑k=1k − 2n∑k=11 = 3n(n+1)2−2n = n(3n−1)2。定数−2もn回足します。

問題 2｜消える和

n∑k=1 1k(k+1) を求めよ。

答えと解説を見る

答え：nn+1

1k(k+1)=1k−1k+1。和は(1−12)+(12−13)+…+(1n−1n+1)=1−1n+1=nn+1。

階差数列

要点

まず覚えること

bn = an+1−an
an = a₁ + n−1∑k=1 bk　(n≥2)

a₁からanまで進む回数はn−1回。そのため、階差もn−1個足します。

なぜ、差をn−1個足すの？

第1項から第2項に進むとき、差を1個足します。第1項から第4項なら、差を足すのは3回です。

a₂ = a₁ + b₁
a₃ = a₁ + b₁ + b₂
a₄ = a₁ + b₁ + b₂ + b₃

だから、第n項までは差をn−1個足します。b₁は「a₂−a₁」、b₂は「a₃−a₂」です。

解くときは、①差を並べる → ②差の一般項を求める → ③初項に差の和を足す。最後に、第1項にも公式が使えるか確認しましょう。

間違えやすいところ

ここに注意
和の上限をnにすると、1つ先の項まで足してしまいます。最後にn=1を確認しましょう。

例題

例題｜問題と解く順番

数列 2, 5, 10, 17, 26, … の一般項を求めよう。

この順番で解こう

  1. 隣り合う項の差を調べる
  2. 初項に、差をn−1個足す
  3. 和の公式を使って計算する
  4. n=1でも合うか確認する

手順1｜隣り合う項の差を調べる

手順 1 / 4

考え方：もとの並びよりも、差の並びの規則が見つけやすいからです。

差を求めると 3, 5, 7, 9, …。よって bk=2k+1。

手順2｜初項に、差をn−1個足す

手順 2 / 4

考え方：第1項から第n項まで進むには、差をn−1回足します。

an=2+n−1∑k=1(2k+1)。

手順3｜和の公式を使って計算する

手順 3 / 4

考え方：差の和を計算すると、第n項をnだけで表せます。

=2+(n−1)n+(n−1)=n²+1。

手順4｜n=1でも合うか確認する

手順 4 / 4

考え方：差の和を使った式はまずn≥2で作ったので、初項も確かめます。

n=1でも1²+1=2。よって、すべての自然数nで an=n²+1。

練習

問題 3｜階差数列

数列 1, 4, 9, 16, … の階差数列の一般項bnと、もとの一般項anを求めよ。

答えと解説を見る

答え：bₙ=2n+1、aₙ=n²

差は3,5,7,…だからbₙ=2n+1。n≥2でaₙ=1+n−1∑k=1(2k+1)=1+n(n−1)+(n−1)=n²。n=1でも一致します。

漸化式

要点

この単元で、何を求める？

問題で与えられるのは、「前の数から次の数を作るルール」です。このルールを表す式が漸化式です。

an+1=an+3
次の数＝今の数＋3

求めたいのは、「何番目かを入れれば、その数が直接分かる式」です。これを一般項といいます。

最初から1つずつ計算せず、100番目などをすぐに求められるようにします。

等差数列なら、足した回数を数える

最初の数が2、毎回3を足す場合を考えます。

2 → 5 → 8 → 11 → …

第1項はまだ3を足していません。第2項は1回、第3項は2回足しています。

だから、第n項までに3を足す回数はn−1回です。

an=2+3(n−1)

100番目ならn=100を入れます。

a₁₀₀=2+3×99=299

等差数列という並びを、漸化式でも一般項でも表せます。

複雑なルールは、分かる形に変える

例えば「2倍して3を足す」というルールなら、

a₁=1、an+1=2an+3

次のように並びます。

何番目1234
もとの数151329
3を足すと481632

3を足した数は、毎回2倍になっています。等比数列の公式が使えそうです。

「分かる形に変える→公式を使う→もとの数に戻す」という順番で一般項を求めます。

何を足すかは、□で探す

最初から3を足すと分かっているわけではありません。足す数を□として、次の形を目指します。

次の数＋□＝2(今の数＋□)

もとのルール「次の数＝2×今の数＋3」を入れ、右側も展開します。

2×今の数＋3＋□
＝2×今の数＋2□

両側にある「2×今の数」を消すと、

3＋□＝2□
□＝3

これで、両方に3を足すと「次は今の2倍」だけの形になると分かります。今の数と次の数を同じにする操作ではありません。

式の形ごとに、解く方針を選ぶ

式の形考え方・一般項
an+1=an+d等差数列：an=a₁+(n−1)d
an+1=ran等比数列：an=a₁rn−1
an+1−an=f(n)階差f(n)をn−1個足す
an+1=pan+q（p≠1）α=pα+qを解き、an−αを等比数列にする

最後の型では、aₙ−αという新しい量を使い、「次は今のp倍」という形を作ります。αは、その形を作るために引く数です。p=1なら等差数列として解けます。

間違えやすいところ

ここに注意
等比数列になったのはaₙ+3です。最後に3を引いて、aₙだけの式に戻しましょう。

例題

例題｜問題と解く順番

a₁=1、an+1=2an+3 の一般項を求めよう。

この順番で解こう

  1. 足す数を□として探す
  2. 両側に3を足して、等比型にする
  3. 新しい数列の初項と公比を確認する
  4. 等比数列の公式を使い、aₙに戻す
  5. 初項と次の項で確かめる

手順1｜足す数を□として探す

手順 1 / 5

「次の数＋□＝2(今の数＋□)」を作りたいので、足す数を探します。

2an＋3＋□
＝2an＋2□
3＋□＝2□
□＝3

だから両側に3を足します。教科書の「αを引く」書き方では、α=−3を引くことと同じです。

手順2｜両側に3を足して、等比型にする

手順 2 / 5

an+1+3=2an+3+3
=2an+6
=2(an+3)

「aₙ+3」という量全体を見ると、次の値は今の2倍です。

手順3｜新しい数列の初項と公比を確認する

手順 3 / 5

考え方：等比数列の一般項には、初項と毎回掛ける数が必要です。

an+3は、初項4・公比2の等比数列。

手順4｜等比数列の公式を使い、aₙに戻す

手順 4 / 5

考え方：公式を使う対象はaₙ+3です。最後に3を引いて戻します。

an+3=4・2n−1。よって an=4・2n−1−3。

手順5｜初項と次の項で確かめる

手順 5 / 5

考え方：求めた式が、問題の条件を満たすかを確認します。

確認：n=1で1、n=2で5。もとの漸化式とも一致。

もう1つの例｜自分で変形してみよう

a₁=3、an+1=3an−4 の一般項を求めます。

  1. α=3α−4より、α=2。
  2. an+1−2=3(an−2)と変形。
  3. an−2は初項3−2=1、公比3の等比数列。
  4. an−2=3n−1なので、an=3n−1+2。

最初の項は3、5、11。一般項でも同じ値になります。

練習

問題 4｜等比型の漸化式

a₁=3、an+1=2an のとき、一般項を求めよ。

答えと解説を見る

答え：aₙ=3・2ⁿ⁻¹

初項3、公比2の等比数列です。第1項では公比をまだ掛けないので、指数はn−1です。

問題 5｜定数を含む漸化式

a₁=2、an+1=3an−4 のとき、一般項を求めよ。

答えと解説を見る

答え：aₙ=2

α=3α−4よりα=2。aₙ₊₁−2=3(aₙ−2)。a₁−2=0なので、aₙ−2=0・3ⁿ⁻¹=0。よってaₙ=2。最初の数項を書いても2,2,2,…と確認できます。

問題 6｜階差型の漸化式

a₁=1、an+1=an+2n のとき、一般項を求めよ。

答えと解説を見る

答え：aₙ=n²−n+1

n≥2でaₙ=1+n−1∑k=12k=1+n(n−1)。n=1でも1なので、aₙ=n²−n+1。

数学的帰納法

要点

まず覚えること

  1. 最初を確認：n=1のときを計算する。
  2. 仮定を置く：n=kで成り立つと仮定する。
  3. 次を示す：その仮定を使い、n=k+1でも成り立つと示す。
  4. 結論を書く：以上より、すべての自然数nで成り立つ。

和の証明では、「k項までの和＋次の1項」に分けるのが定番です。

計算して確かめるだけでは、なぜ足りない？

n=1、2、3で確かめても、n=100や1000で成り立つとはまだ言えません。帰納法では、「1つ成り立てば、その次も必ず成り立つ」ことを示します。

最初のn=1が成り立ち、1から2、2から3…とつなげられれば、すべての自然数へ進めます。

和の問題では、n=k+1の左辺から書き始め、「kまでの部分」を仮定で置き換えると進めやすくなります。

答案に必要な3点
①最初の場合の確認
②n=kで成り立つという仮定
③その仮定を使ったn=k+1の証明
最後に「以上より、すべての自然数nで成り立つ」と結びます。

間違えやすいところ

ここに注意
n=k+1で成り立つことを最初から仮定しないこと。「示したい式」へ、仮定を使って変形します。

例題

例題｜問題と解く順番

1+3+5+…+(2n−1)=n² を数学的帰納法で証明しよう。

この順番で解こう

  1. 最初のn=1を確認する
  2. n=kで成り立つと仮定する
  3. 次の1項を足す
  4. 次も成り立つことを確かめ、結論を書く

手順1｜最初のn=1を確認する

手順 1 / 4

nに1を入れます。

左辺=1　右辺=1²=1

両辺が等しいので、最初の場合は成り立ちます。

手順2｜n=kで成り立つと仮定する

手順 2 / 4

1+3+…+(2k−1)=k²

これを、この後の変形で使います。「仮定」は、次の番号でも成り立つと示すための出発点です。

手順3｜次の1項を足す

手順 3 / 4

n=k+1の左辺は、kまでの和に次の項2k+1を足したものです。

{1+3+…+(2k−1)}+(2k+1)

波かっこの中を、手順2の仮定を使ってk²に置き換えます。

k²+(2k+1)=(k+1)²

手順4｜次も成り立つことを確かめ、結論を書く

手順 4 / 4

得られた(k+1)²は、示したい式にn=k+1を入れた右辺です。

n=1で成り立ち、n=kで成り立つならn=k+1でも成り立つ。よって、すべての自然数nで成り立ちます。

練習

問題 7｜和の等式を証明

1+2+…+n=n(n+1)2 を数学的帰納法で証明せよ。

答えと解説を見る

答え：最初の確認と、kからk+1への証明を書く

①n=1で両辺は1。②n=kで成り立つと仮定する。n=k+1で左辺は{1+…+k}+(k+1)=k(k+1)2+(k+1)=k+1)(k+22。これはn=k+1の右辺。①②よりすべての自然数nで成り立ちます。

分数型の漸化式

要点

まず、文字を数字にして読もう

an+1=an−16an−7

これは「今の数から、次の数を作る式」です。

n=1なら　a₂=a₁−16a₁−7

a₁=1を入れると、

a₂=1−161−7=52

下の小さな数字は、何番目の数かを表します。掛け算ではありません。

この型で、やりたいこと

分数の式のままでは、毎回同じ数を足す・掛ける形が見えません。

そこで、次の順に形を変えます。

  1. 同じ数を引く — 分子に共通の形を作る。
  2. 逆数にする — 分子と分母を入れ替える。
  3. 新しい名前bₙを付ける — 長い式を短く書く。

最後にbₙの式を、aₙの式に戻します。

引く数は、計算して探す

引く数を、まだ分からない数xとして探します。

「今の数も次の数もxだったら？」と考え、aₙとaₙ₊₁を両方xにします。

x=x−16x−7

両辺にx−7を掛けて整理します（x≠7）。

x(x−7)=x−16
x²−8x+16=0
(x−4)²=0
x=4

だから、この例では4を引くと考えます。xは数列の番号ではなく、引く数を見つけるための仮の文字です。

一般式の文字も確認したいとき

一般式は、さまざまな問題を1つの形で表したものです。最初から覚えなくても、数字の例で手順を確認できます。

p・q・r・s・αの意味
an+1=pan+qran+s

p・q・r・sは、問題で決まる一定の数です。この例ではp=1、q=−16、r=1、s=−7です。

α（アルファ）は「引く数」に付けた名前です。今回はα=4。新しい操作ではなく、4などの数を文字で表しただけです。

例題

例題｜問題と解く順番

a₁=1、an+1=an−16an−7。一般項を求めよう。

一般項は、nを入れればn番目の数が分かる式です。a₁、a₂、a₃を全部計算しなくても、aₙを直接求められる形にします。

この順番で解こう

  1. 4を引く理由を確認
  2. 4を引いて、通分する
  3. 0で割らないことを確認
  4. 逆数を取り、新しい名前を付ける
  5. 右側を「一定の数＋同じ分数」に分ける
  6. bₙの一般項を求める
  7. bₙの名前を元に戻す

手順1｜4を引く理由を確認

手順 1 / 7

要点で、x=x−16x−7を解くとx=4になりました。

4を引くと、左も右も「項−4」という形になります。実際に計算して確かめましょう。

手順2｜4を引いて、通分する

手順 2 / 7

an+1−4=an−16an−7−4

後ろの4にも、同じ分母を付けます。

4=4(an−7)an−7

分母をそろえ、分子を引きます。

an+1−4=an−16−4(an−7)an−7
=−3(an−4)an−7

左はaₙ₊₁−4、右の分子はaₙ−4。同じ形ができました。

手順3｜0で割らないことを確認

手順 3 / 7

このあとaₙ−4で割るので、aₙ=4にならないことを確かめます。

a₁=1は4より小さい数です。またaₙ<4とすると、直前の式の分子−3(aₙ−4)は正、分母aₙ−7は負。よってaₙ₊₁−4<0、つまり次も4より小さい数です。

これを繰り返せるので、すべての項は4より小さく、4にも7にもなりません。したがって以下の割り算ができます。

手順4｜逆数を取り、新しい名前を付ける

手順 4 / 7

1an+1−4=an−7−3(an−4)

左の形が長いので、次の名前を付けます。

bn=1an−4

bₙは、右の分数全体に付けた別名です。nが1ならb₁、次の項ならbₙ₊₁と書きます。

手順5｜右側を「一定の数＋同じ分数」に分ける

手順 5 / 7

分子を、分母にあるaₙ−4を使って書き直します。

an−7=(an−4)−3

これを入れて、分数を2つに分けます。

bn+1=(an−4)−3−3(an−4)
=an−4−3(an−4)+−3−3(an−4)
=−13+1an−4
=bn−13

bₙは毎回13ずつ減る等差数列になりました。

手順6｜bₙの一般項を求める

手順 6 / 7

b1=1a₁−4=11−4=−13

初項が−13、公差も−13です。第n項まではn−1回進むので、

bn=−13+(n−1)(−13)
=−n3

手順7｜bₙの名前を元に戻す

手順 7 / 7

求めたいのはbₙではなくaₙです。bₙに付けた名前を戻します。

1an−4=−n3

両辺の逆数を取り、最後に4を足します。

an−4=−3n
an=4−3n

n=1で1、n=2で52。最初に求めた値とも一致します。

練習

問題 18｜逆数に置き換える

a₁=2、an+1=2an−9an−4。一般項を求めよ。

答えと、そう考える理由を見る

1．なぜ3を引くのか

引く数をxとして、今も次もxになる式を作ります。

x=2x−9x−4
x(x−4)=2x−9
x²−6x+9=0
(x−3)²=0
x=3

ここから3が見つかるので、3を引きます。突然3を選んだわけではありません。

2．3を引き、分母をそろえる

an+1−3=2an−9an−4−3
=2an−9−3(an−4)an−4
=−an+3an−4
=−an−3an−4

左と右の分子に「項−3」ができました。

3．逆数を取ってよいか確認

a₁=2<3。aₙ<3なら、aₙ−3もaₙ−4も負です。上の式の右側は「負の数同士の分数にマイナス」なので負。よってaₙ₊₁<3です。

このため、すべての項は3より小さく、aₙ−3もaₙ−4も0になりません。

4．bₙは、分数全体の別名

bn=1an−3

とおきます。逆数を取った式の分子を、(aₙ−3)−1と分けます。

bn+1=an−4−(an−3)
=(an−3)−1−(an−3)
=−1+1an−3
=bn−1

bₙは、毎回1ずつ減る等差数列です。

5．初項と公差でbₙを求める

b1=12−3=−1
bn=−1+(n−1)(−1)=−n

6．aₙの式に戻す

1an−3=−n
an−3=−1n
an=3−1n

n=1でa₁=2となり、最初の条件を満たします。

Sn+1はa₁からan+1まで、Snはa₁からanまでの和。引くと、最後のan+1だけが残ります。

確率分布と期待値

要点

Xは、何を数える文字？

例えば、硬貨を2回投げて「表が出た回数」をXとします。

裏・裏 → X=0
表・裏 → X=1
裏・表 → X=1
表・表 → X=2

Xは硬貨そのものではなく、結果を見て数えた「0回・1回・2回」の数です。

確率分布は、値と確率の対応表

表1回になる結果は2通りあります。表0回と2回は、それぞれ1通りです。

表の回数X012
その確率142414

値を並べ、その下に確率を書く。この表が確率分布です。確率の合計は1になります。

期待値の計算は「掛けて、足す」

期待値は、次の計算で求めます。

値 × その値が出る確率
を、それぞれ計算して足す

例えば、100円が90％、0円が10％で当たるくじなら、

100×0.9 + 0×0.1 = 90円

100円がよく出るので、平均も100円に近い90円になります。90円が当たるという意味ではありません。

E(X)は「期待値を表す記号」

E(X)と書かれていたら、「Xの値に、それぞれの確率を掛けて足そう」と読みます。硬貨2回の例なら、

E(X)=0×14+1×12+2×14
=1

同じことを何度も繰り返したとき、1回の試行あたりの表の回数の平均は1に近づいていきます。毎回必ず1回になるわけではありません。

確率が同じかどうかを確認する

Xの値が0・1・2の3種類あっても、それぞれの確率が13とは限りません。

「その値になる結果は何通りか」を先に数えましょう。期待値を求める前には、確率の合計が1になるか確認します。

例題

例題｜問題と解く順番

この順番で解こう

  1. 起こり得る結果を書き出す
  2. 表の回数ごとに、確率をまとめる
  3. 値と確率を掛けて、足す

手順1｜起こり得る結果を書き出す

手順 1 / 3

2回の順番も区別して書きます。

（裏,裏） （表,裏）
（裏,表） （表,表）

どれも同じ確率なので、1通りの確率は14です。

手順2｜表の回数ごとに、確率をまとめる

手順 2 / 3

表0回は1通り、1回は2通り、2回は1通りです。

X012
確率141214

確率を全部足すと1。すべての結果を数えられています。

手順3｜値と確率を掛けて、足す

手順 3 / 3

E(X)=0×14+1×12+2×14
=0+12+12=1

答えは1回。式の0・1・2は表の回数、その隣の分数はその回数になる確率です。

分散・標準偏差

要点

分散は、平均からの離れ方を見る数

次の2つは、どちらも平均が2です。

A：必ず2が出る
B：1と3が半分ずつ出る

Aはいつも平均と同じ。Bは平均より1小さいか、1大きい値が出ます。平均が同じでも、平均からどれくらい離れるかは違います。それを数で表すのが分散です。

平均との差を2乗する理由

1と3が半分ずつ出る例では、平均との差は次の通りです。

1−2=−1
3−2=1

そのまま足すと正と負が消えます。そこで2乗してから、それぞれの確率を掛けて足します。

分散=(−1)²×12+1²×12=1

計算では、2つの値を先に出す

E(X²)と{E(X)}²は、計算する順番が違います。

  1. E(X²)：各値を2乗し、確率を掛けて足す。
  2. {E(X)}²：期待値を求め、その答えを2乗する。
V(X)=E(X²)−{E(X)}²

V(X)は分散を表す記号です。左の計算結果から右の計算結果を引きます。

標準偏差は、分散の平方根

分散を求めたら、平方根を取ると標準偏差になります。

σ(X)=√V(X)

例えば分散が4なら、標準偏差は√4=2。分散と標準偏差を求める問題では、最後の平方根を忘れないようにします。

例題

例題｜問題と解く順番

X=0,1,2の確率がそれぞれ14,12,14のとき、分散と標準偏差を求めよう。

この順番で解こう

  1. 期待値E(X)を求める
  2. 各値を2乗し、確率を掛けて足す
  3. 期待値の2乗を引く
  4. 分散の平方根を取る

手順1｜期待値E(X)を求める

手順 1 / 4

最初に、0・1・2それぞれに確率を掛けて足します。

E(X)=0×14+1×12+2×14
=1

手順2｜各値を2乗し、確率を掛けて足す

手順 2 / 4

E(X²)=0²×14+1²×12+2²×14
=0+12+1=32

2を2乗した4に14を掛けると1です。確率まで2乗しないようにしましょう。

手順3｜期待値の2乗を引く

手順 3 / 4

手順1の期待値は1。これを2乗して引きます。

V(X)=32−1²=12

手順4｜分散の平方根を取る

手順 4 / 4

σ(X)=√(12)=√22

答えは、分散が12、標準偏差が√22です。

練習

確率変数の変換・和

要点

Y=2X+5は、どんな操作？

Xをもとの値、Yを計算した後の値とします。

Y=2X+5
Xを2倍してから、5を足す

例えばX=3ならY=11。どの値にも同じ操作をするので、平均も2倍して5を足すことになります。

全員に同じ点を足しても、差は変わらない

例えば40点と60点の2人に、それぞれ5点を足すと、45点と65点になります。

もとの点数差：60−40=20
変えた後の差：65−45=20

平均は5点上がりますが、平均からの離れ方は変わりません。だから、分散には「+5」を入れません。

2倍すると、なぜ分散は4倍？

値を2倍すると、平均との差も2倍です。分散は差を2乗して計算するため、

(2×差)²=4×差²

となります。つまり、分散は4倍、標準偏差は2倍です。一般には次の式を使います。

E(aX+b)=aE(X)+b
V(aX+b)=a²V(X)
σ(aX+b)=|a|σ(X)

独立なら、差の場合も分散を足す

独立は、一方の結果を知っても、もう一方の結果の確率が変わらないこと。例えば、別々のさいころの出目を考えます。

E(X−Y)=E(X)−E(Y)
独立なら
V(X−Y)=V(X)+V(Y)

Yを引くことは、Yを−1倍して足すことです。分散では(−1)²=1になるので、分散を足します。独立という条件を確認してから使いましょう。

和の公式も確認する

E(X+Y)=E(X)+E(Y)
独立なら
V(X+Y)=V(X)+V(Y)

期待値は足して求められます。分散も足してよいと判断するには、独立かどうかを確認します。

例題

例題｜問題と解く順番

E(X)=3、V(X)=2 のとき、Y=2X+5の期待値・分散・標準偏差を求めよう。

この順番で解こう

  1. 期待値を求める
  2. 分散を求める
  3. 標準偏差を求める

手順1｜期待値を求める

手順 1 / 3

E(Y)=2E(X)+5
=2×3+5=11

値を2倍して5を足すので、平均も同じように変わります。

手順2｜分散を求める

手順 2 / 3

V(Y)=2²V(X)
=4×2=8

分散は2倍ではなく2²倍。平均との差が2倍になり、その差を2乗するからです。全員に5を足しても散らばりは変わりません。

手順3｜標準偏差を求める

手順 3 / 3

σ(Y)=√V(Y)
=√8=2√2

最後に、分散の平方根を取ります。

問題 11｜独立な確率変数の差

差の分散でも引き算にしません。

二項分布

要点

まず、何回成功したかを数える

例えば、硬貨を5回投げ、表が出た回数をXとします。表が出たら「成功」と呼ぶことにします。

試す回数 n=5
1回で成功する確率 p=12

二項分布B(n,p)は、同じ成功確率で独立にn回試したときの、成功回数の分布です。B(5,12)なら、この硬貨の例を表します。

ちょうど3回なら、1通りの並びを考える

「表・表・表・裏・裏」という並びの確率は、各回の確率を掛けます。

(12)³(12)²=132

左の指数3は表の回数、右の指数2は裏の回数です。でも、これ以外の並び方もあります。

表が出る場所の選び方を掛ける

5回のうち、表が出る3か所の選び方は10通りです。

5C3=5×4×33×2×1=10
求める確率=10×132=516

ほかの並び方もまとめて数えるために、組合せの数を掛けます。一般式は、

P(X=k)=nCkpk(1−p)n−k

期待値・分散はnとpを入れる

期待値 E(X)=np
分散 V(X)=np(1−p)
標準偏差 σ(X)=√{np(1−p)}

nは試す回数、pは1回の成功確率、1−pは失敗する確率です。まずnとpを書き出してから公式に入れましょう。

「少なくとも1回」は、反対を考える

「少なくとも1回成功する」の反対は、「1回も成功しない」です。

求める確率=1−全部失敗する確率

例えば硬貨を4回投げるなら、全部裏の確率を引きます。

1−(12)⁴=1516

くじを引いて戻さない場合のように、毎回の成功確率が変わるときは、二項分布の公式をそのまま使えません。

p=12（表が出る確率）
k=3（求めたい表の回数）

裏の回数は5−3=2、裏の確率は1−12=12です。

手順 2 / 4

P(X=3)=5C3(12)³(12)²
=10×132=516

手順 3 / 4

E(X)=np=5×12=52

期待値は2.5回。何度も5回投げを繰り返したときの、表の回数の平均に対応します。1回の試行で表が2.5回出るという意味ではありません。

手順4｜分散を求める

手順 4 / 4

V(X)=np(1−p)
=5×12×12=54

正規分布と標準化

要点

正規分布は、面積で確率を表す

平均の近くの値が出やすく、平均から遠い値は出にくい、左右対称の分布です。

形をつかむための概念図

曲線の下の面積全体が1。ある範囲の面積が、その範囲に入る確率になります。

N(60,100)を読み取る

N(平均, 分散)
N(60,100)なら
平均=60、分散=100
標準偏差=√100=10

Nの2つ目は標準偏差ではなく分散です。割り算に使うのは、平方根を取った10です。

標準化は「平均を引いて、標準偏差で割る」

平均60点、標準偏差10点なら、70点は平均より10点上です。10点を基準にして測り直すと、

Z=70−6010=1

となります。50点なら50−6010=−1。平均より上なら正、下なら負です。

一般には Z=X−μσ

標準正規分布表の読み方

標準正規分布表は、計算後のZが0からzまでに入る確率を調べる表です。ここではzが0以上の場合を載せています。

例えばz=1.25を調べるときは、次の順に見ます。

  1. 左端から「1.2」の行を探す。
  2. 上端から「0.05」の列を探す。
  3. 交わるところの0.3944を読む。
1.2+0.05=1.25
A(1.25)=0.3944

これは、Zが0から1.25の間に入る確率が39.44％という意味です。

z=0.00〜3.99を、0.01刻みで調べられます。例題・練習の画面からも開けます。

中央なら足す、右端なら引く

平均より右側全体の面積は0.5です。A(1)=0.3413を使うと、

−1から1まで：
0.3413+0.3413=0.6826

1より右側：
0.5−0.3413=0.1587

先に「どこからどこまでの確率か」を確認すると、足すか引くかが決まります。

発展：回数の分布を、正規分布で近似

発展：二項分布を正規分布で近似する

nが十分大きく、pが0や1に偏りすぎないとき、B(n,p)はN(np,np(1−p))で近似できます。

連続補正を使う場合、整数値のXについて「a≤X≤b」を、対応する正規変数Yの「a−0.5≤Y≤b+0.5」に置き換えます。授業での扱い・問題の指定に合わせましょう。

  1. 平均と標準偏差を読む
  2. 50点と70点を、それぞれ変換する
